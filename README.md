# ASSAM_HORNBILL_TIGERS

Official website for the **Assam Hornbill Tigers** franchise competing in the **Indian Softball Cricket League (ISCL)**.

## Overview
- **Franchise**: Assam Hornbill Tigers
- **League**: Indian Softball Cricket League (ISCL)
- **Tech Stack**: React, Vite, Tailwind CSS, Vanilla CSS

## Features
- **Cinematic Roadmap Highway**: Scroll-driven Season 1 journey and milestone reveals with authentic match imagery.
- **Match Center & Standings**: Real-time scores, timeline breakdowns, and fixtures.
- **The Den & Fan Zone**: Official news, club history, squad roster, and high-resolution wallpaper downloads.
- **Official ISCL Portal Link**: Direct integration with [isclcricket.in](https://isclcricket.in/) for Season 2 registrations.

## Setup & Running Locally
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
