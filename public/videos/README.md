# Match Video Highlights

Place video clips or highlights of matches in this folder. The app expects the following filenames:

| Match ID | Match Description                    | Expected Filename  |
|----------|--------------------------------------|--------------------|
| 1        | Highlights vs Mumbai Kings           | `match-1.mp4`      |
| 2        | Highlights vs Delhi Capitals          | `match-2.mp4`      |

## Recommended Specs
- **Format:** MP4 (H.264 video codec, AAC audio codec)
- **Resolution:** 1280×720 (720p) or 1920×1080 (1080p)
- **Framerate:** 30fps or 60fps
- **Compression:** High compression (keep files under 15-20MB for fast loading on web)
